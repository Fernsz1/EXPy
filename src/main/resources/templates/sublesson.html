Lesson Walkthrough

Step 1

Hello World & Print

Every Python journey starts with print(). Use it to display text or the value of a variable. 

print("Hello, World!")
greeting = "Hello, EXPy!"
print(greeting)
Step 2

Variables & Data Types

Store information by assigning names. Python infers the data type automatically, so you can swap values freely. 

username = "Nova"
age = 16
pi = 3.1416
is_wizard = True
Step 3

User Input

Use input() to interact with the player. Convert the result when you need numeric values. 

spell = input("Name your spell: ")
power = int(input("Power level (0-10): "))
print(f"{spell} has power {power}!")
